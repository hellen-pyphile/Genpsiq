## 📌 Sobre o Projeto
O **GenPsiq** é um website desenvolvido como Trabalho de Conclusão de Curso (TCC) para obtenção do título de Técnico em Desenvolvimento de Sistemas pela ETEC Doutor Celso Giglio.

O objetivo principal da plataforma é promover um canal de suporte acadêmico para estudantes e interessados na área da genética psiquiátrica. O projeto busca combater a desvalorização da ciência no Brasil, facilitar a busca por objetos de estudo e fornecer ferramentas seguras para o aprendizado e a divulgação científica.

## 🚀 Funcionalidades
- [x] **Relatório Psiquiátrico (Anamnese):** Disponibiliza casos fictícios de pacientes para estudo prático de habilidades clínicas, permitindo acompanhar etapas de evolução e comparar laudos psicológicos (com exemplos corretos e incorretos).
- [x] **Filtragem e Publicação de Artigos:** Ferramenta dedicada a facilitar a pesquisa acadêmica, permitindo aos usuários localizar artigos sobre doenças psicológicas de forma objetiva, além de um recurso para que autores da área publiquem suas obras[cite: 2].
- [x] **Comunidade Interativa:** Espaço focado em conectar estudantes e profissionais para tirar dúvidas, colaborar e responder questões sobre psicologia[cite: 2].
- [x] **Sistema de Autenticação:** Página de login e cadastro para garantir a segurança da plataforma e evitar que as informações sejam corrompidas por insciência[cite: 2].

## ⚙️ Como Executar o Projeto

### Pré-requisitos
Como o projeto utiliza **PHP** no back-end[cite: 2], você precisará de um ambiente de servidor local instalado em sua máquina, como [XAMPP](https://www.apachefriends.org/pt_br/index.html) ou [WampServer]. 

### Instalação
1. Clone este repositório no seu terminal:
```bash
git clone [https://github.com/hellen-pyphile/Genpsiq.git](https://github.com/hellen-pyphile/Genpsiq.git)
```

2. Mova a pasta extraída (`Genpsiq`) para o diretório público do seu servidor local:
   - **Se usar o XAMPP:** mova para a pasta `C:\xampp\htdocs\`
   - **Se usar o WampServer:** mova para a pasta `C:\wamp64\www\`
3. Abra o painel de controlo do seu servidor local (ex: XAMPP Control Panel) e inicie o módulo **Apache**.
4. Abra o navegador da sua preferência e acesse o endereço:

```text
http://localhost/Genpsiq
